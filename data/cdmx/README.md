# CDMX Data

This directory should contain the following files before running any Tier 1 or Tier 2b CDMX scripts.

## Required files

### 1. STC Metro daily ridership
**File:** `afluencia/afluenciastc_simple_12_2025.csv`

Source: Secretaría de Movilidad del Gobierno de la Ciudad de México (SEMOVI)  
Portal: https://datos.cdmx.gob.mx/dataset/afluencia-diaria-del-metro-cdmx  
Coverage: 2010–2025 (use 2022–2025 for this paper)  
Columns expected: `fecha`, `linea`, `estacion`, `afluencia`

### 2. Other transit modes (Tier 1 only)
**Files:** `afluencia/afluenciamb_simple_12_2025.csv` (Metrobús),  
`afluenciartp_desglosado_12_2025.csv` (RTP),  
`afluencia_desglosada_cb_12_2025.csv` (Cablebús),  
`afluencia_tren_ligero_simple_12_2025.csv` (Tren Ligero)

Same source portal as STC Metro above.

### 3. Processed multimodal file (generated)
**File:** `_outputs/afluencia_multimodal_long.csv`

Generated by running the CDMX preprocessing notebook:
```bash
python src/paper/tier1/cdmx_shocks.py --preprocess
```

### 4. CDMX event catalog (required for Tier 2b GNN)
**File:** `event_catalog_2016_2025.csv`

Curated catalog of high-impact events at Estadio Azteca and alternate CDMX venues (2016–2025). Used as the training and evaluation set for `src/paper/tier2/cdmx_gnn_loto.py`.

Expected columns: `fecha`, `venue`, `event_category`, `description`, and optionally `kickoff_local`, `attendance`.

This file is committed to the repository as part of the curated data assets.

## Privacy note
Raw ridership data are publicly available through SEMOVI's open-data portal and contain no personal information. Station-level daily totals only.
